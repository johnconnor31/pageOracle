# pageOracle

A lightweight Next.js starter for an AI-powered reading assistant that lets users select text on any website and ask follow-up questions.

## Features
- Landing page for the product concept
- Modern Next.js app setup
- Ready for extension into a browser AI assistant or web app

## Local setup

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Project idea
`pageOracle` is designed for users who want to:
- highlight text on a webpage
- ask AI what it means
- get a summary, explanation, or quick insight in context
